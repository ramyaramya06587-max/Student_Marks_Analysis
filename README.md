# Student Marks Analysis

## Project Overview
This Python project analyzes student marks and calculates basic statistics.

## Features
- Calculate total marks.
- Calculate average marks.
- Find the highest marks.
- Find the lowest marks.

## Technologies Used
- Python
- Jupyter Notebook
- Visual Studio Code

## Sample Data
[85, 90, 78, 92, 88]

## Results
- Total Marks: 433
- Average Marks: 86.6
- Highest Marks: 92
- Lowest Marks: 78

## How to Run
Open student_marks_analysis.ipynb in VS Code and run the code cells.
